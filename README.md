# agent-platform (POC — specs in BETA)

Meta-agent orchestrator: capability catalog, lockbuild, routing cascade
(agent → template/B1.5 → B1 → B2), human-gated certification, templated agent UIs.

- Specs: `docs/` — start with `docs/ROADMAP.md` §0 (document consumption model).
- Build sessions (Claude Code / Codex): configured by `CLAUDE.md` / `AGENTS.md`.
  First session: "Implement Phase 0 per docs/ROADMAP.md".
- `catalog.lock.yaml` is generated by `tooling/lockbuild` — never committed by hand,
  verified by CI (build-twice diff + lock-matches-tree).

Role A (B2 candidate generation) is dispatched into scratch workspaces with the playbook
injected per run — never from this checkout. See `docs/ROADMAP.md` §0 and §7.
